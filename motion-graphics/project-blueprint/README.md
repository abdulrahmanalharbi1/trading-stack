# مخطط المشروع · موشن قرافيك عن إدارة المشاريع

عرض متحرك عربي مدته دقيقتان ونصف (1920×1080، 30 إطاراً في الثانية) يشرح إدارة المشاريع في عشر لوحات، ومعه موسيقى ومؤثرات صوتية مولَّدة بالكود ومتزامنة مع الحركة.

| اللوحة | الموضوع | التوقيت |
|---|---|---|
| — | الغلاف | 0:00 |
| ١ | ما هو المشروع؟ (تعريف PMBOK والخصائص الثلاث) | 0:09 |
| ٢ | المثلث الذهبي وأثر طلب التغيير | 0:20 |
| ٣ | دورة الحياة وحلقة المراقبة والتحكم | 0:33 |
| ٤ | البدء: ميثاق المشروع وخريطة أصحاب المصلحة | 0:45 |
| ٥ | التخطيط: هيكل تجزئة العمل WBS | 0:57 |
| ٦ | التخطيط: مخطط جانت والمسار الحرج | 1:08 |
| ٧ | التنفيذ: لوحة كانبان وحدّ العمل الجاري | 1:22 |
| ٨ | المراقبة: القيمة المكتسبة (SPI و CPI و EAC) ومصفوفة المخاطر | 1:33 |

| ١٠ | المنهجيات: الشلال والرشيقة | 2:08 |
| — | الخاتمة | 2:19 |

كل الأرقام تتبع مشروعاً واحداً («إطلاق متجر إلكتروني»)، وهي متسقة من لوحة إلى أخرى. مثال ذلك أن المسار الحرج يساوي ١٣ أسبوعاً، وأن SPI = ١٨٠ ÷ ٢٠٠ = ٠٫٩٠، وأن EAC = ٤٨٠ ÷ ٠٫٨٥٧ ≈ ٥٦٠ ألف.

## طريقة البناء

- `src/main.js`: خط زمني واحد متوقف من GSAP، ومعه الدالة `renderAll(t)`. كل إطار دالة خالصة في الزمن، لذلك يعمل الكود نفسه في المشغّل المباشر وفي تصدير الفيديو إطاراً بإطار.
- `src/head.html` و `src/body.html`: التنسيقات وهيكل الصفحة والمشغّل.
- `synth.py`: يولّد الموسيقى والمؤثرات من `cues.json`، وهي نقاط التزامن التي يصدّرها الخط الزمني نفسه.
- `build.py`: يجمع الأجزاء في صفحة واحدة، ويضمّن الصوت إن مُرّر ملفه.
- `harness.js` و `probe.js` و `render.js`: تشغّل الصفحة في Playwright وتلتقط إطاراتها.

## إعادة التوليد

```bash
# 1) الأصول المحلية: gsap.min.js والخطوط من Google Fonts توضع في assets/ (راجع harness.js)
python3 build.py                       # index.html بلا صوت
node probe.js ""                       # يصدّر cues.json
python3 synth.py                       # soundtrack.wav  (يتطلب numpy و scipy)
ffmpeg -i soundtrack.wav -b:a 128k soundtrack.mp3
python3 build.py soundtrack.mp3 project-blueprint.html
node render.js 0 4500                  # frames/f00000.jpg … (يمكن تقسيمه على عدة عمليات)
ffmpeg -framerate 30 -i frames/f%05d.jpg -i soundtrack.wav \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart project-blueprint.mp4
```
